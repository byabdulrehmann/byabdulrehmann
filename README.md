## Featured projects

### VISE: Video Intelligence & Segmentation Engine
**[Repository](https://github.com/byabdulrehmann/UVOS-Unsupervised-video-object-segmentation)** · Final Year Project · Research paper

An unsupervised video object segmentation framework that finds and segments the primary
moving objects in a video without labelled masks. RGB frames and optical-flow maps are
encoded by two parallel streams aligned with cross-modal contrastive learning, and an
attention-guided decoder (CBAM) produces the segmentation mask. Evaluated on DAVIS 2016,
FBMS and YouTube-Objects, and delivered as a web application for uploading videos and
downloading segmented results.

<p align="center"><img src="https://raw.githubusercontent.com/byabdulrehmann/UVOS-Unsupervised-video-object-segmentation/main/docs/architecture.png" alt="VISE architecture" width="85%" /></p>

`Python` `PyTorch` `Computer Vision` `Contrastive Learning` `Optical Flow (RAFT)` `CBAM`

### TradBot-I: Real-Time Voice AI Assistant
**[Repository](https://github.com/byabdulrehmann/TradBot-I)** · **[Watch the demo](https://github.com/byabdulrehmann/TradBot-I/blob/main/docs/jarvis-demo.mp4)**

A real-time voice AI desktop assistant built on the Gemini Live API that can hear, see, speak
and control the computer on Windows, macOS and Linux. A holographic 3D face lip-syncs its
replies, and the assistant handles web search, files, apps, reminders and system settings
through a plugin system, with persistent memory, undo and a confirmation gate for risky
actions. Includes a read-only MetaTrader 5 market monitor with live prices, spreads and
trend context.

`Python` `Gemini Live API` `Real-time Audio` `AI Agents` `PyQt6` `MetaTrader 5`

### AI Trading Journal
**[Repository](https://github.com/byabdulrehmann/AI-Trading-Journal)**

A performance-analytics platform with an LLM coach that answers only from the user's own
records, citing the trades behind each answer. Pluggable model providers with model
discovery and in-chat switching, user-controlled memory, and a privacy setting that decides
exactly what is shared with the model. Built as a secure full-stack application with
encrypted credentials, per-user data isolation and end-to-end tests.
