## 🚀 Featured projects

### 🎥 VISE: Video Intelligence & Segmentation Engine
**[Repository](https://github.com/byabdulrehmann/Unsupervised-Video-Object-Segmentation)** · Final Year Project · Research paper

Finds and segments the main moving objects in a video **without labelled masks**. RGB frames and optical-flow maps run through two parallel encoders aligned with cross-modal contrastive learning, and an attention-guided decoder (CBAM) draws the mask. Evaluated on DAVIS 2016, FBMS and YouTube-Objects, and shipped as a web app for uploading videos and downloading results.

<p align="center"><img src="https://raw.githubusercontent.com/byabdulrehmann/Unsupervised-Video-Object-Segmentation/main/docs/architecture.png" alt="VISE architecture" width="85%" /></p>

> **Skills:** Deep learning · Unsupervised learning · Contrastive learning · Optical flow (RAFT) · Attention modules · Benchmark evaluation · Research writing

### 🎙️ TradBot-I: Real-Time Voice AI Assistant
**[Repository](https://github.com/byabdulrehmann/TradBot-I)** · **[Watch the demo](https://github.com/byabdulrehmann/TradBot-I/blob/main/docs/jarvis-demo.mp4)**

A voice AI desktop assistant on the Gemini Live API that can hear, see, speak and control the computer on Windows, macOS and Linux. A holographic 3D face lip-syncs its replies, and a plugin system handles web search, files, apps, reminders and settings, with persistent memory, undo and a confirmation gate for risky actions.

> **Skills:** AI agents · Real-time audio streaming · Tool calling · Desktop automation · Plugin architecture · Safety guardrails · Desktop UI

### 📊 AI Trading Journal
**[Repository](https://github.com/byabdulrehmann/AI-Trading-Journal)**

A performance-analytics platform with an **LLM coach that answers only from the user's own records** and cites the trades behind each answer. Pluggable model providers with in-chat switching, user-controlled memory, and a privacy setting that decides exactly what reaches the model. Built secure: encrypted credentials, per-user data isolation and end-to-end tests.
